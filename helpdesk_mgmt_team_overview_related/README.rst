Bridge addon between helpdesk_mgmt_team_overview and
helpdesk_mgmt_ticket_related_users.

Adds the tickets where a user is a related user to the Team Performance
dashboard:

-  Related ticket counter next to the Main and Extra objectives, without
   affecting the progress rings.
-  Avatars (up to 5) of the owners of those tickets.
-  Panel split into "Own Tickets" and "Related Tickets" sections.
