In the portal view, tickets created by portal users are automatically
assigned to the default user configured in the Helpdesk category. If the
option to allow team selection in the portal is enabled, the module
checks whether the default user of the category belongs to the selected
team. – If yes, the ticket is assigned to that user. – If not, it is
assigned to the team leader.

The list of assignable users is restricted to internal users only,
ensuring proper assignment control and avoiding assigning tickets to
portal users.

Known issues / Roadmap
======================

When a ticket is created from the portal and the team field is set as
visible in the system configuration, the ticket should be automatically
assigned to an internal user who belongs to the team selected by the
portal user.
