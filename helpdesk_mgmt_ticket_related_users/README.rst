Allows assigning related users to helpdesk tickets in addition to the
usual participants. It makes it possible to involve people who are not
part of the main workflow but need to stay informed or collaborate
occasionally. Related users have access to a new section called “My
related tickets”, where they can view all the tickets in which they have
some level of participation. This improves traceability, collaboration,
and information visibility within the helpdesk.

Usage
=====

When creating a new ticket, you can assign any number of related users
directly from the form view. Once assigned, these users can access their
related tickets by clicking on “Tickets” and then “My related tickets”,
which will open the standard Kanban view displaying only the tickets
where they have been added as related users. Additionally, it is
possible to filter tickets in the search view by related users, making
it easier to track and manage tickets where a user has indirect
participation.
