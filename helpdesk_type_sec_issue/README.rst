Bug Tracker
===========

Bugs are tracked on `GitHub Issues <https://github.com/solvosci/slv-helpdesk/issues>`_.
In case of trouble, please check there if your issue has already been reported.

`feedback <https://github.com/solvosci/slv-helpdesk/issues/new?body=module:%20helpdesk_type_sec_issue%0Aversion:%2013.0%0A%0A**Steps%20to%20reproduce**%0A-%20...%0A%0A**Current%20behavior**%0A%0A**Expected%20behavior**>`_.
